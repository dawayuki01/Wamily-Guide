# insta-caption — Wamily Instagram キャプション生成

Wamily（@wamily.jp / Instagram）の投稿キャプションを、サワディーの声・Wamilyの世界観で生成するskill。

note記事より**短く・パンチが効く・スクロールを止める**キャプションを目指す。

---

## 起動条件

ユーザー（サワディー）が以下のいずれかを言ったら起動：

- 「インスタのキャプション書いて」「Instagram投稿のキャプション作って」
- 「○○の投稿作りたい」「○○についてインスタにあげたい」
- `/insta-caption` と明示的に呼び出された
- 旅行中・旅行後の写真について「これ投稿したい」と漏らした

## Wamily Instagramの世界観

### 核となるスタンス

- **居場所みたいなガイドブック**
- **友達**として届ける（広告主や情報源ではない）
- **おかえり**と言える場所
- 営業臭・煽り・誇張は徹底排除

### 「Wamilyらしい」キャプションとは

- **読み手の旅・家族の時間に寄り添う**
- **小さな発見を一緒に味わう**
- **完璧じゃない、未完成だからこそ温かい**
- **押しつけがましくない**

NG感覚：「○○へ行こう！」「今すぐチェック！」「絶対おすすめ」「必見スポット」

OK感覚：「ふと足を止めた場所」「子どもがゲラゲラ笑ってた」「あの空気感、伝わるかな」

## サワディー文体ルール（Instagram版）

### 1. 文字数の戦略

- **Instagramは最初の125文字で勝負**（ここで「もっと読む」を押させる）
- **総文字数の目安**：300〜800字（読みやすさ重視。長すぎると読まれない）
- **告知・コンセプト系**は1500字までOK（フォロワーが読む前提）

### 2. 書き出し（1〜3行目が命）

3パターンの型：

**A. 情景から入る**
> 「ロンドンの3月、息子がベンチで桜を見ていた。」

**B. 一言の感情から入る**
> 「ふと、これが居場所なんだと思った。」

**C. 問いから入る**
> 「子連れの旅、何が一番嬉しかったって聞かれたら？」

### 3. 一人称・呼称

- 一人称：**「僕」**（基本）／「僕たち家族」
- 妻：**「妻」**
- 子ども：**「息子」「子どもたち」**（年齢具体は避ける）

### 4. 段落・改行

- **1〜2文で改行**（モバイル前提・読みやすさ最優先）
- **空行を多用**して呼吸を作る
- 1ブロックは2〜3行まで

### 5. 語尾・トーン

- **「〜です」「〜ます」基調**（noteより少し丁寧）
- **時々「〜だ」「〜だぜ」「〜やん」**でリズムをつける
- 関西弁チラ見せは1箇所程度（多用しない）

### 6. 締め方

3パターン：

**A. 余韻型**
> 「あの夕方の空気、いまも覚えてる。」

**B. 共感呼びかけ型**
> 「同じような場所、ありますか？」

**C. CTA型（控えめに）**
> 「ガイドブック、プロフィールのリンクから🌱」

### 7. 絵文字

- **多くて投稿全体で2〜3個**
- 使うなら：🌱（種・芽吹き・Wamilyのキー絵文字）/ 🐶 / 🌍 / ☕️ / ✏️
- ❤️😭🥰のような感情絵文字は基本使わない

### 8. NGワード

- **絶対NG**：「必見」「話題」「驚き」「完全ガイド」「○○選」「厳選」「最強」「マジで」「ガチで」
- **避けたい**：「○○すぎる」「やばい」（口語的すぎる煽り）
- **避けたい**：マーケ的フレーズ全般、上から目線

## 投稿タイプ別の構成テンプレ

### A. 旅の一場面（エッセイ系）

写真：旅先のシーン。情景が伝わる写真。

```
【書き出し】情景の描写 / 感情の一言（125字以内に核を込める）
   ↓
【中盤】そのシーンで起きたこと・感じたこと
   - 短い段落 × 2〜3個
   - 子どもの様子・自分の感情
   ↓
【締め】余韻 or 問いかけ
   ↓
【ハッシュタグ】（後述）
```

長さ：300〜500字

### B. スポット紹介（情報系）

写真：そのスポットの雰囲気がわかる1〜複数枚。

```
【書き出し】スポット名 + 一言の特徴
   例：「○○の○○、子連れにこそ来てほしい場所。」
   ↓
【なぜ良かったか】具体的なエピソード
   - 何が起きた / 子どもの反応
   ↓
【実用情報】場所・営業時間など最小限
   - 詳細は「ガイドブック見てね」で逃がす
   ↓
【CTA】「プロフィールのリンク🌱」など控えめに
   ↓
【ハッシュタグ】
```

長さ：400〜700字

### C. 思想シェア（コンセプト系）

写真：象徴的な1枚。家族の後ろ姿、空、本など。

```
【書き出し】問い or 気づき
   例：「家族で旅する意味って何だろう。」
   ↓
【展開】サワディーの視点・体験
   - 揺れも含めた率直な話
   ↓
【気づき】「なるほどな」と思える瞬間
   ↓
【締め】余韻 or 共感呼びかけ
   ↓
【ハッシュタグ】
```

長さ：500〜1000字

### D. 告知（イベント・公開・お知らせ）

写真：Wamilyビジュアル / 関連スクショ。

```
【書き出し】告知の核（1〜2文）
   ↓
【背景】なぜそれをするのか・想い
   - 営業臭NG、淡々と
   ↓
【内容】何が・いつ・どうやって
   - 箇条書きで簡潔に
   ↓
【CTA】参加方法・リンク誘導
   ↓
【ハッシュタグ】
```

長さ：500〜1500字（重要告知は長めOK）

## ハッシュタグ戦略

Instagramのハッシュタグは**最大30個**まで設定可能。
**10〜15個程度を最適範囲**として、毎回ベースセット + 投稿固有タグ で組む。

### ベースセット（毎投稿に入れる候補）

```
#Wamily #ワミリー
#子連れ海外旅行 #子連れ旅行 #子連れ海外
#家族旅行 #海外家族旅行
#ガイドブック
#旅と家族 #子どものいる暮らし
```

### 投稿タイプ別の追加候補

**A. 旅の一場面**
```
#{都市名旅行} （例：#ロンドン旅行）
#{都市名子連れ}
#トラベルログ #travelwithkids
```

**B. スポット紹介**
```
#{都市名グルメ} #{都市名カフェ} など具体タグ
#子連れカフェ #子連れスポット
#kidfriendly
```

**C. 思想シェア**
```
#家族時間 #子育て #海外子育て
#夫婦の時間 #パートナーシップ
```

**D. 告知**
```
#お知らせ #ガイドブック #wamily更新
```

### ハッシュタグの注意

- **過度な英語ハッシュタグ**は日本人ファミリー向けには弱い → 日本語中心
- **ハッシュタグだけの行で改行**して本文と切り離す（見た目重要）
- **競合・大量タグ（#travel #love #instagood）は避ける**（埋もれる）
- **中規模タグ（投稿数10万〜100万）が最も発見されやすい**

## 品質チェックリスト（生成後・自己レビュー）

ドラフトを返す前に自己チェック：

- [ ] 一人称が「僕」になっているか
- [ ] 最初の125字で「もっと読む」を押したくなる魅力があるか
- [ ] NGワード（必見・話題・最強・マジで等）が混入していないか
- [ ] 営業臭・上から目線がないか
- [ ] 段落が長すぎないか（モバイルで読みやすいか）
- [ ] 絵文字が多用されていないか（多くて2〜3個）
- [ ] ハッシュタグが10〜15個前後か
- [ ] ハッシュタグが本文と改行で区切られているか
- [ ] ファクトチェックできない数字・地名を作っていないか
- [ ] 子どもの呼称が「息子」で統一されているか（娘ではない）
- [ ] 写真とのセットで完成する想定になっているか

## 投稿について

Instagram Graph APIで投稿自体は技術的に可能だが、**画像・動画ファイルとビジュアルの判断**は人がやるもの。

skillの出力をサワディーがコピペ → Notion Instagram投稿DBに保存 → 写真を選んで投稿予約、という流れ。

**重要**：SNSは"いつ・どんな温度で出すか"が肝。skillは制作補助まで、最後の決定はサワディーが握る。

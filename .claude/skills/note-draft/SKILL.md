# note-draft — サワディーのnote記事下書き生成

サワディー（澤田智之）が note（https://note.com/tomosawa）に投稿する記事の下書きを、本人の文体で生成する skill。

完成版を目指さず、**「最後の温度調整だけサワディーがやればいい」状態**まで持っていくのが目的。

---

## 起動条件

ユーザー（サワディー）が以下のいずれかを言ったら起動する：

- 「note記事の下書きを書いて」「note書きたい」
- 「○○のことをnoteにしたい」（○○＝旅行先・出来事・思想）
- `/note-draft` と明示的に呼び出された
- 旅行から帰ったあと「○○のこと書きたいな」と漏らした

## ユーザーへのヒアリング

以下を質問して、足りない情報を埋める。一気に全部聞かず、必要なら段階的に：

| 項目 | 例 |
|---|---|
| **テーマ・出来事** | 「ロンドンで子どもが熱出した夜」「Wamilyガイドブック公開した話」 |
| **素材・メモ** | 断片的なテキスト・写真キャプション・ツイートの引用など |
| **記事タイプ** | エッセイ系 / コンセプト系（任意。判断つかなければ skill 側で提案） |
| **想定読者** | 既存フォロワー / Wamilyに興味ある人 / 家族で海外行きたい人 など |
| **長さ** | 短め（1500字）/ 標準（2500〜3500字）/ 長め（5000字〜） |
| **CTA有無** | あり（フォーム誘導など）/ なし（純粋なエッセイ） |

素材が乏しい時は、サワディーに **「もう少し具体的な情景・セリフ・感情を聞かせてください」** と返す。
ファクト不足のまま生成すると嘘になる。**架空の数字・年齢・地名は絶対に作らない**。

## サワディー文体ルール（最重要）

過去記事から抽出した文体パターン。これを守ること。

### 1. 一人称・呼称

- 一人称：**「僕」**（基本）／「私たち家族」（家族として語る時）
- 妻：**「妻」**（名前を出すなら「妻のかな多」。フルネーム「岡嶋かな多」「澤田かな多」も文脈で使い分け）
- 子ども：**「息子」「子どもたち」「2人の息子」**（年齢具体は避ける、または「3歳と1歳」のように記事執筆時点を明示）
- 自称：「家族愛強めパパ🐶サワディー」（自己紹介の冒頭で稀に使う）

### 2. 語尾・口調

- **混在OK**：「〜です」「〜ます」「〜だ」「〜だぜ」「〜やん」「〜ちゃう」
- **関西弁を控えめに混ぜる**：「ほんまにおもろい」「めっちゃ」「やってもうた」
- 同じ段落で丁寧語と砕けた語尾が同居しても自然
- 自分ツッコミ：「これ2回もやってもうた」「ここだけの秘密ってことで」

### 3. 段落・リズム

- 一段落は **3〜5文程度**、短めに切る
- **改行（`<br>` または空行）を多用**して呼吸を作る
- 一つの感情・一つの場面で一段落
- 長文を続けない

### 4. 強調

- **太字を多用**（noteの `**word**` 構文）
- 強調するのは「キーフレーズ」「核となる気持ち」「決意の言葉」
- 例：**「妻の活躍を、特等席で応援し続ける」** **「あの人がいるあの国に、家族で行ってみよう」** **「疲れたけど最高だったね！」**

### 5. 接続詞のクセ

- **「だがしかし、」** ← 急展開
- **「とわいえ、」** ← 冷静に戻る
- **「けれど、」** ← 揺り戻し
- **「そして、」** ← 静かな前進
- **「だがしかし、」「けれども、」**（複数バリエーション）

### 6. 感情表現

- 率直に：「ちょっぴり泣きそうになった」「ウルウルしてた」「グッとくる」
- 揺れを隠さない：「葛藤する姿を僕は毎日見ていた」
- 楽しんでる感：「めっちゃおもろい」「ほんまにおもろい」「笑えてくる」
- カッコつけない：「おセンチなハートを逆撫でする」

### 7. 締め方（記事のラスト）

二択：

**A. 楽観・信頼で締める**
> 「あの時行ってよかった、絶対そう言えるような未来が来る、僕は信じてる。」
> 「未来へのすべての可能性を広げる種になるはずだから。」

**B. 決意・宣言で締める**
> 「よーしゃ、楽しくなるぜ！！！」
> 「妻よ、突き抜けてこい、ぶち上げてこい。」

CTA記事の場合は「気軽にご連絡いただけると嬉しいです！」など柔らかく。

### 8. 絵文字

- 控えめ。多くて記事全体で2〜3個
- 使うとしたら 🐶（犬）🌍 🌱 程度
- 顔文字や😭😂のような感情絵文字は使わない

### 9. 言葉選び（よく使う表現の辞書）

| カテゴリ | 表現 |
|---|---|
| 妻について | 「天才の妻」「世界一かっこいい人」「クリエイター岡嶋かな多」 |
| 子どもについて | 「キュートな2人の息子」「愛する大切な子ども」「尊い」「美しい」 |
| 時間について | 「1分1秒がまたとない特別な"何か"」「刹那的な時間」「貴重」「味わい尽くしたる」 |
| 挑戦について | 「ちょっぴり挑戦したい家族の背中を優しく押す」「特等席で応援」 |
| 家族について | 「家族愛」「家族の営み」「家族らしいパートナーシップ」 |
| 旅について | 「家族での海外渡航は最高だけど超大変」「疲れたけど最高だったね！」 |
| 未来について | 「未来へのすべての可能性を広げる種」「あの時行ってよかった」 |

### 10. NGワード・避けたい表現

- **絶対NG**：「必見」「話題」「驚き」「完全ガイド」「○○選」「厳選」「最高峰」「圧倒的」
- 避けたい：「最強」「最強の」「マジで〇〇すぎる」（過度に煽る系）
- 避けたい：マーケ的・営業的フレーズ全般
- 避けたい：「皆さん〇〇しましょう！」のような上から目線
- ファクトチェックできない数字・固有名詞は出さない

## 記事タイプ別の構成テンプレ

### エッセイ系（参考：n69a6c5dc7211「妻は世界へ、僕は家で」）

見出しなしで一気に流す。出来事→揺れる感情→決意の構造。

```
【書き出し】事実から入る（1〜2文）
  例：「妻が海外の作家と曲を書きまくる修行にでた、期間はなんと3週間。」

【背景・補足】必要なら引用ブロックで補足
  例：ユーロビジョンとは何か（wikiから引用）

【感情の揺れ】葛藤・嬉しさ・寂しさを率直に
  - 「本当にかっこいいママだぜ」
  - 「葛藤する姿を僕は毎日見ていた」
  - 「ちょっぴり泣きそうになった」

【自分ツッコミ・笑い】重さを抜く
  - 「ウィンカー出したいのにワイパーが動き出す」
  - 「ここだけの秘密ってことで」

【視点の転換】「とわいえ、」「だがしかし、」で気持ちを切り替える

【決意・宣言】楽しくなるぜ！！！で締める
  - 「よーしゃ、楽しくなるぜ！！！」
  - 「妻よ、突き抜けてこい、ぶち上げてこい。」
```

長さ：1500〜2500字程度。

### コンセプト系（参考：n54e221b21c04「Wamily はじめます」）

見出し（h2/h3）でしっかり構造化。提案・サービス紹介・想いの表明に使う。

```
【書き出し】自己紹介＋宣言
  「こんにちわ、家族愛強めパパ🐶サワディーです。」
  「そんな僕がこの度、○○をはじめます。」

## 章タイトル（テーマの土台）
  - 自分たちの状況・家族紹介
  - 大切にしていること

## 章タイトル（問題提起）
  - 「だがしかし、〇〇って本当に大変…」
  - リアルな困りごと・体験

## 章タイトル（気づき・救い）
  - 「○○に支えられて、最高の経験になった」
  - 具体的なエピソード2つ程度

## 章タイトル（思想・洞察）
  - 「○○が、圧倒的な価値になる。」
  - 太字でキーフレーズを強調

## 章タイトル（提案・宣言）
  - 「あの人がいるあの国に、家族で行ってみよう。」
  - 自分が動く理由・宣言

## 章タイトル（CTA）
  - 「家族で海外へ、Wamilyが寄り添います！」
  - 連絡先・呼びかけ

## 章タイトル（補足・展望）
  - 取り組み一覧（箇条書き）
  - 一緒にやれる人募集
```

長さ：3500〜5500字程度。

## 出力フォーマット

skillが完成稿をユーザーに返すときは、以下の形式で：

````markdown

## 🎯 タイトル候補（3案）

1. **○○○○○○○** — エモい寄り
2. **○○○○○○○** — シンプル寄り
3. **○○○○○○○** — 関西弁チラ見せ

## 🗺️ 構成

| セクション | 概要 |
|---|---|
| 書き出し | xxx |
| 中盤 | xxx |
| 締め | xxx |

## ✍️ 本文ドラフト

（ここに本文。note貼り付け用のmarkdown形式。**太字**・改行・引用ブロックなどを反映）

---

## 💡 補足
- このドラフトは「最後の温度調整だけサワディーがやる」前提
- ファクト確認が必要な箇所：（あれば列挙）
- 写真の差し込み推奨ポイント：（記事中の場所を指示）
````

## 品質チェックリスト（生成後・自己レビュー）

ドラフトを返す前に、自分で以下をチェック：

- [ ] 一人称が「僕」になっているか（「私」「俺」になっていないか）
- [ ] 文体が記事タイプに合っているか（エッセイ系/コンセプト系）
- [ ] 段落が長すぎないか（5文以上の段落は分割検討）
- [ ] 太字でキーフレーズが強調されているか（記事全体で5〜10箇所）
- [ ] NGワード（必見・話題・〇〇選など）が混入していないか
- [ ] 営業臭・上から目線のフレーズがないか
- [ ] ファクトチェックできない具体数字・年齢・地名を作っていないか
- [ ] 締めが「楽観・信頼」または「決意・宣言」のパターンになっているか
- [ ] 関西弁・自分ツッコミが1〜2箇所入っているか（入れすぎ注意）
- [ ] 子どもの呼称が「息子」で統一されているか（娘ではない）

## 投稿について

note APIには公開エンドポイントがないため、**投稿自体は自動化しない**。

skillの出力をサワディーが note エディタにコピペ → 写真・装飾を整える → 公開、という流れ。

将来的に NotionやObsidian経由でドラフト管理したくなったら、追加でskillを拡張する。
